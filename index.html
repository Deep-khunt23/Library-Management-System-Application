Enterprise Core Features

Engineered for Reliability and Everyday Ease

Designed for schools, colleges, community centers, and personal collections that want high reliability without complicated cloud logins.

📊

Live KPI Dashboard

Four distinct metric panels keep you updated on total titles, physical copies, registered readers, active borrow counts, and overdue fines at a glance.

📚

Sortable Inventory Catalog

Click any column header to sort titles, authors, categories, ISBNs, or stock numbers ascending or descending. Full-text search filters rows in real time.

🛡️

3-Book Borrow Limit

Enforces maximum fairness. Patrons holding 3 active unreturned books are blocked from borrowing more until previous books are returned.

💰

Automated Fine Engine

Calculates late fees at ₹5.00 per day past the 14-day loan schedule. Shows instant popup receipts with overdue days and exact fine totals.

🔒

Active Loan Delete Guards

Prevents accidental data loss. Neither books with active loans nor patrons with unreturned materials can be deleted until books are safely returned.

🌓

Dark & Light Mode Switcher

CustomTkinter provides smooth transition between sleek Dark Mode and high-contrast Light Mode, dynamically adapting treeviews and cards.

Built-In Verification & Business Rules

🛑
Out of Stock Prevention
If a book's available_copies <= 0, issue is blocked with "No copies available".
🪪
Email Format & Uniqueness
Regex validates user@domain.com and prevents duplicate registrations in SQLite.
📅
Automatic 14-Day Lending Cycle
Loans automatically timestamp issue date as today and set due date to exactly today + 14 days.
🛡️
Foreign Key Integrity
Transactions map directly to Book and Member tables with PRAGMA foreign_keys = ON.

FAQ

Frequently Asked Questions

Does this application require an active Internet connection?

No. LMS Pro is 100% offline-first. All data is securely stored locally in an embedded SQLite database (library.db) right beside the executable.

Can I back up or transfer the database to another PC?

Yes! Simply copy the library.db file to a USB drive or cloud backup. Moving it to another computer running LMS Pro restores your entire library instantly.

Can I run this from source code using Python?

Yes. Run pip install -r requirements.txt followed by python main.py to launch from source or make modifications.
